Password Strength Checker

A simple Python program that checks the strength of a password based on length, character variety, and special characters.

Features
-Checks if a password contains:
  Lowercase letters
  Uppercase letters
  Numbers
  Special characters (@#$%^&+=!)
-Evaluates password strength as Weak, Medium, or Strong.

Requirements
  -Python 3.x
  -re module (standard library, no installation required)
